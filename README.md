# 六爻工作台 · Liuyao Workbench

> **把千年玄学装进现代工具链。** 一个纯前端的六爻排盘与卦例管理应用：从铜钱摇卦到深度地支分析，从手绘画板到 Markdown 双向同步，从真太阳时校准到 24 节气高精度历法——一卦一录，卦卦可考。

**版本 1.0.1（正式版）** · Web / Windows / Android 三端 · React 18 + Vite 5 + Tailwind CSS 3 + IndexedDB

## ✨ 亮点与优势

### 🎨 玄穹主题 — 为占卜而生的视觉设计
- **深空极光 + 玻璃拟态**：极光漂移背景、卡片光标光斑、微光按钮，明暗双主题（浅色/跟随系统/深色三选），跟随系统自动切换

- **日建晚子时换日**：23:00 起换次日干支，旬空/时柱同步跟随；年干支按立春换年、五虎遁精确遁干

- **自定用神**：六亲/地支二选一，金色高亮盘面，伏神命中同样点亮
- **纳甲纳干**：按上下经卦各自纳甲（乾甲壬/坤乙癸/震庚/巽辛/坎戊/离己/艮丙/兑丁）

- 手绘/箭头/矩形/圆形/文字，四角拖拽调形，粗细独立记忆
- 涂鸦以 SVG 内嵌 Markdown，**导出-导入完全可逆**

### 📚 卦例管理全流程
- 卦例库：标签/反馈状态/创建时间多维筛选，关键字搜索，批量导出/导入 md

- 统计复盘：正确率、错题本、按标签聚合——用数据见证断卦水平

## 🚀 快速开始

### Web 版（浏览器）

```bash
npm install      # 安装依赖（首次）
npm run dev      # 开发模式，浏览器打开 http://localhost:5173
npm run build    # 生产构建，产物在 dist/
npm run preview  # 本地预览构建产物
```

> 数据保存在浏览器本地 IndexedDB，无需服务器。清理浏览器数据前请先「设置 → 数据备份」导出 JSON。

### Windows 版（exe）

需要 [Rust 工具链](https://www.rust-lang.org/tools/install)（1.77+）：

```bash
npm install
npm run tauri:dev     # 开发调试（本机窗口运行）
npm run tauri:build   # 打包 exe 安装程序（产物在 src-tauri/target/release/bundle/）
```

### Android 版（APK）

需要 [JDK 17+](https://adoptium.net/) 与 [Android SDK](https://developer.android.com/studio)（设置 `ANDROID_HOME` 环境变量）：

```bash
npm install
npm run tauri:android:init   # 首次初始化 Android 工程
npm run tauri:android:build  # 打包 APK（产物在 src-tauri/gen/android/app/build/outputs/apk/）
```
