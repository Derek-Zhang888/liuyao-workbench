# 六爻工作台（测试版）

> 本地排盘与卦例管理工具：9 种起卦方式、自占断记录、卦例库与回收站、Markdown 导入导出、统计复盘与错题本、辅助资料页。暗色专业风，桌面/手机双视窗响应式。
>
> 版本：0.1.0（测试版）｜技术栈：React 18 + Vite 5 + Tailwind CSS 3 + IndexedDB

## 启动方法

```bash
npm install   # 首次运行安装依赖
npm run dev   # 启动开发服务器
```

浏览器打开 http://localhost:5173 （端口被占用时会自动顺延，以终端提示为准）。

> 数据全部保存在浏览器本地 IndexedDB 中，无需服务器、不联网。清理浏览器数据前请先在「设置 → 数据备份」导出 JSON 备份。

## 功能清单

| 模块 | 功能 |
|---|---|
| 排盘 | 起卦时间可选新历/农历（默认当前时刻，全部起卦方式通用）；8 种起卦方式：钱币卦（逐爻输入三枚钱币正/背面）、爻名卦、卦名卦、数字卦（两算法）、报数卦、时间卦、电脑卦（交互/一键）、分秒卦 |
| 盘面 | 本卦/变卦、六神、六亲、世应、爻画与动爻、旺衰、伏神、伏藏；干支历（年/月/日/时建、旬空、卦身、煞神）；五行配色；点击卦名看卦辞、点爻位看爻辞 |
| 占断 | 断语/应期/备注/反馈四栏 + 吉凶勾选 + 已反馈联动对错记录（吉凶/应期/方位），默认未反馈 |
| 卦例库 | 保存/列表/标签·反馈状态筛选/关键字搜索/详情编辑/单条与批量导出 md/批量删除/导入 md（失败清单提示） |
| 回收站 | 删除进回收站，保留天数可设（默认 30 天），到期自动清理；可恢复/彻底删除/清空 |
| 统计 | 总数/已反馈/未反馈总览；吉凶/应期/方位正确率（仅统计已反馈）；按标签筛选；错题本（任选错误维度筛选，展开复盘） |
| 辅助页 ×5 | 卦辞爻辞（64 卦卦辞 + 384 爻辞原文）、六十甲子纳音表、十二长生表、生克冲合关系图（十二地支圆环 + 六亲生克图）、常见取象表 |

| 响应式 | ≥1024px 三栏排盘（起卦｜盘面｜占断）+ 左侧导航；768–1023px 两栏（起卦+盘面并排、占断在下）；<768px 顶部 Tab + 更多菜单 + 纵向滚动 |

## Markdown 格式（卦例交换）

导出/导入采用三层格式：front matter（标题/日期/标签/反馈状态/对错/起卦参数）+ 盘面表格 + 断语/应期/备注/反馈各节。
起卦参数完整可逆——导入时自动重新排盘恢复盘面；缺起卦参数的 md 会被拒绝导入。

## 已知限制（测试版）

- **爻辞解析为占位**：卦辞爻辞页展示原文，「解析」一栏显示「解析整理中…」，后续迭代补充网络解析（将标注来源与免责声明）。
- **浏览器多文件下载拦截**：批量导出 md 时若浏览器拦截后续下载，请在下载提示中选择「允许本站下载多个文件」后重试。
- **数据存浏览器本地**：换浏览器/清理缓存数据即丢失，请定期在「设置 → 数据备份」导出 JSON 备份；浏览器版本过旧可能不支持 IndexedDB。
- **干支历法仅供参考**：农历/干支转换采用公开算法，个别边界日期可能与权威历书有出入；旺衰为简化版本（旺/相/休/囚/死）。
- **排盘历史仅最近 20 条**：回填查看历史卦例时保存会新建一条记录，不会覆盖原卦例。
