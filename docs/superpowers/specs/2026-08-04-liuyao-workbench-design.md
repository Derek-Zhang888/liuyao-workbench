# 六爻工作台 — 设计文档

> 日期：2026-08-04 ｜ 状态：已确认 ｜ 技术栈：React + Vite + Tailwind CSS + IndexedDB

## 1. 背景与目标

用户为六爻爱好者，参考「六爻排盘宝」APK（已拆包分析：9 种起卦方式、64 卦纳甲表、盘面 UI 结构）开发自己的「六爻工作台」：排盘 + 自占断（用户手写断语）+ 卦例本地保存 + Markdown 导入导出 + 占断统计与错题本。

**差异化**：原 App 导出 sqlite/txt 且无统计；本工作台以 Markdown+front matter 为交换格式（可逆导入），具备已反馈/未反馈统计体系和错题本。

## 2. 平台与技术栈

- **当前形态**：HTML 网页版工作台，响应式适配桌面/手机视窗（断点 768px）
- **预留**：后续用 Tauri 打包为 Windows exe + 安卓 APK（前端本体即 React+Vite）
- **技术栈**：React 18 + Vite + Tailwind CSS + IndexedDB（浏览器内置数据库）
- **风格**：暗色专业风（深色底 + 金/朱红强调），五行配色（青/赤/黄/白/黑）

## 3. 架构原则（为后续改动服务）

1. **组件化**：每个功能独立组件，改一个不动其他
2. **数据层独立**：IndexedDB 封装统一接口，后续换存储只改一层
3. **排盘引擎纯函数**：输入参数 → 输出盘面，无副作用
4. **配置驱动**：起卦方式、预置 tag、五行配色均为配置文件
5. **测试版优先**：核心链路先完整，辅助页内容后续迭代

## 4. 页面结构（6 大页面）

### ① 排盘页（主页）
- 起卦方式栏：9 种方式（爻名/钱币/卦名/数字/报数/时间/电脑/分秒/时刻）
- 盘面区：干净盘面（五行配色、不内置卦辞爻辞）
- 占断区：断语(文本) / 应期(文本) / 吉凶(勾选吉·凶) / 备注(文本) / 反馈(文本)
  - 已反馈/未反馈勾选（默认未反馈）；勾选已反馈后展开：吉凶对错(必填) / 应期对错(选填) / 方位对错(选填)
- 操作：保存卦例 / 导出 md / 排盘历史
- 盘面交互：点击卦名 → 卦象+卦辞页；点击爻位 → 爻辞页

### ② 卦例库页
- 分类筛选：占分类 tag / 已反馈·未反馈 / 搜索
- 列表：标题、日期、吉凶标记、对错标记
- 操作：单条/批量导出 md、导入 md、编辑、删除（进回收站）
- 回收站：保留时间可设置（默认 30 天），到期自动清理；可恢复/彻底删除

### ③ 统计页
- 总览：总数 / 已反馈数 / 未反馈数
- 正确率：吉凶对错 / 应期对错 / 方位对错（仅统计已反馈）
- 按 tag 筛选正确率（如只看占财运）
- 错题本：筛选"吉凶错 / 应期错 / 方位错"的卦例，点开复盘

### ④ 辅助页 ×5（顶部按钮进入）
1. 卦辞爻辞：卦名→卦象+卦辞；爻位→爻辞+解析（解析爬取网络，标注"解析源于网络，自行判断取用"）
2. 六十甲子纳音表（文字颜色随纳音五行变化）
3. 十二长生表（文字按五行配色）
4. 生克冲合关系图（十二地支/六亲刑冲克害关系图）
5. 常见取象表（爻位/十二地支/六亲六兽取象）
- 测试版：先放表格/占位，解析内容第二批迭代

### ⑤ 设置页
- 回收站保留天数、数据备份（导出/导入 JSON）

## 5. 数据模型（IndexedDB 三张表）

```
① 卦例表 guashi
   id | title | 起卦方式 | 起卦参数(输入值+时间) | 盘面快照JSON
   | 断语 | 应期 | 吉凶(吉/凶) | 备注 | 反馈
   | 状态(已反馈/未反馈) | 吉凶对错 | 应期对错 | 方位对错
   | tags[] | 创建时间 | 更新时间 | 已删除标记+删除时间

② 标签表 tags：id | name | color | is_default
   （预置：占病/占财运/占婚姻/出行/考试/寻物/等反馈/代占卦…+ 自定义新增）

③ 设置表 settings：回收站保留天数、主题等
```

**卦例双存储**：起卦参数（md 导入恢复用）+ 盘面快照（即时显示用）。

## 6. Markdown 格式（三层设计）

```markdown
---
title: 占测今日出行
date: 2026-08-04
tags: [出行, 等反馈]
status: 未反馈
吉凶: 吉
吉凶对错: ""
应期对错: ""
方位对错: ""
起卦参数: 钱币卦|211111|2026-08-04 14:30
---

# 占测今日出行

## 盘面
（人类可读盘面表格）

## 断语
（自占断内容）

## 应期
（预计应验时间）

## 备注
（补充说明）

## 反馈
（实际结果验证）
```

**导入规则**：front matter 必须完整（含起卦参数），否则拒绝导入并提示；正文可自由编辑，导入时从起卦参数重新排盘恢复盘面，正文各节合并进对应字段。

## 7. 排盘引擎（独立模块）

```
gua_table.js   64卦静态表（移植自原 App b4.java：卦宫/卦名/爻画/世应/六亲地支/伏神/游魂归魂）
gan_zhi.js     干支历法：公历→农历干支、旬空、月破、卦身、神煞
qigua.js       9 种起卦算法 → 统一输出 本卦爻画+动爻
paipan.js      盘面生成：查表→本卦/变卦、六神排布(青龙朱雀勾陈螣蛇白虎玄武)、
               旺衰、五行配色、伏神
```

起卦算法要点：
- 数字卦：①第1÷8上卦，(2+3)÷8下卦，(1+2+3)÷6动爻 ②各数独立÷8÷6
- 报数卦：2-8 位，前两=卦数(1-8)，后=动爻编号(1-6)
- 分秒卦：分钟两数和÷8上卦，秒两数和÷8下卦，四数和÷6动爻
- 时刻卦：月日时刻四数，3数和÷8上卦，4数和÷8下卦，4数和÷6动爻
- 电脑卦：随机（交互/直接）

## 8. 统计与反馈流

- 保存默认「未反馈」；事后编辑卦例补记反馈+对错 → 状态转「已反馈」
- 统计仅计算已反馈卦例：总数、吉凶/应期/方位对错数、正确率（%）
- 错题本 = 已反馈中任一维度为错的卦例
- 回收站：删除 → 标记 deleted+删除时间 → 恢复/彻底删除 → 超期自动清理（设置天数）

## 9. 响应式

- ≥768px 桌面版：左侧导航 + 排盘三栏（起卦方式|盘面|占断输入）

- F12 设备模拟器可预览手机版
