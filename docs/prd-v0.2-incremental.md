# 六爻工作台 v0.2 增量 PRD（盘面画板 / 盘面标记 / 香闺床帐 / 占断增强）

> 版本：v0.2（增量）｜基于已交付 v0.1.0｜技术预研结论由主理人拍板，本文照实纳入，不新增架构。

## 一、产品目标

一句话：**让盘面「可画、可标、可读、可导」——新增涂鸦画板与 11 项盘面标记开关、香闺/床帐、占断背景与笔记，并全部同步到 md 导出/导入，保持纯前端、向后兼容、多端可打包。**

## 二、需求池（P0 核心必做 / P1 重要 / P2 可选）

### P0（本迭代核心，必须交付）

**A. 盘面画板（涂鸦）**
- 描述：起卦盘面增加画板开关（位于「盘面信息」下方、「地支分析」上方，二者中间）；开启后可在盘面上自由涂鸦，交互参考 QQ 截图工具。
- 验收：
  1. 画笔支持 30 档粗细 + 多颜色；文字输入可放置于盘面；形状含矩形/圆形/画线/箭头。
  2. 矩形/圆形支持「外框/填充」切换 + 30 档粗细 + 颜色；箭头支持颜色 + 30 档粗细。
  3. 颜色提供预设色块 + 调色板。
  4. 涂鸦数据存为矢量 JSON（record 独立字段 `guashi.doodle`），保存卦例时一并保存。
  5. 导出 md 时生成 SVG data URI 快照，内嵌于「盘面信息」与「占断信息」之间（节顺序：盘面→涂鸦→地支分析→断语）。
  6. 导入 md 时按元数据 JSON 可逆还原涂鸦；旧 md 无涂鸦节时不报错。
  7. 取消勾选画板时弹窗警告「将清除涂鸦内容」，确认后才清除（复用 ConfirmDialog）。
  8. 画板开启时拦截爻位点击（覆盖卦名行 + 爻行区域，不遮挡地支分析区）；跨页/刷新保留纳入 sessionStorage。

**B. 盘面标记增强（设置页 11 个开关，默认全关，开启后盘面即时展示）**
- 描述：设置页「盘面选项」卡片（与现有 nagan 开关同卡片）新增 11 个开关；开启后对应标记在盘面爻行区域即时显示，要求整齐清晰（具体样式由架构师设计，建议角标/小字形式）。
- 验收：
  1. 旺相休囚死：每个爻位地支五行右上角显示小字（旺/相/休/囚/死），直读引擎 `yao.wangshuai`。
  2. 月破 / 日破：爻被月建/日建所冲时显示对应标记（静爻休囚细分按引擎口径）。
  3. 月合 / 日合：爻与月建/日建六合时显示对应标记。
  4. 回头生 / 回头克 / 回头冲 / 回头合：四个独立开关，仅动爻显示；生/克直读引擎 `benBianLabel`，冲/合需新增判定。
  5. 化进退 + 反伏吟（合并为一个开关）：化进/化退直读引擎；反伏吟按「本变对应爻地支相同=伏吟、相冲=反吟」新增判定。
  6. 日月建显示六亲：盘面干支行月建/日建旁显示其地支五行对应六亲（以卦宫五行为基准，需新增计算）。
  7. 开关默认全关；旧卦例快照无对应字段时跳过展示，不报错（向后兼容）。

**C. 香闺 / 床帐（盘面卦身旁）**
- 描述：盘面信息中卦身旁边显示香闺与床帐。
- 验收：
  1. 卦身算法升级为精确推演（阳世从子、阴世从午，从初爻数至世爻，六爻排盘宝口径）。
  2. 香闺 = 卦身五行所克之五行对应的爻（如卦身酉金→克木→显示「香闺：寅木」）。
  3. 床帐 = 卦身五行所生之五行对应的爻（如金生水→显示「床帐：子水」）。
  4. 显示内容为地支五行，样式与卦身相邻对齐。

**D. 占断页增强**
- 描述：卦题输入框下新增「背景」文本框（位于断语之上）；「备注」栏改名为「笔记」。
- 验收：
  1. record 新增背景字段（如 `background`），DuanInput 组件新增背景输入框，顺序：卦题→背景→断语。
  2. 「备注」栏 UI 标签与字段展示名改为「笔记」；字段名建议保留 `beizhu` 避免数据迁移（最终由架构师评估）。
  3. 旧卦例无背景字段时正常显示为空，不报错。

**E. md 导出模板更新 + 导入兼容**
- 描述：需求 B/C/D 内容与需求 A 涂鸦快照均同步进 md 导出；导入端保持新旧兼容。
- 验收：
  1. 导出 md 中盘面信息含：B 的盘面标记（由 panSnapshot 重算）、C 的香闺/床帐、D 的背景与笔记，保持源码级等宽对齐（延续 exportMd.js 现有风格）。
  2. md 新增「涂鸦」快照节（SVG data URI）与「背景」节；「笔记」改名需兼容旧 md「备注」节仍可导入。
  3. importMd.js 新增解析：涂鸦节还原、背景节、新节名兼容；旧 md 导入不崩、新 md 被旧版导入不崩（仅丢新字段）。
  4. 导入后 UI 按 method/params 重排盘面，盘面标记自动恢复。

**F. 多端打包兼容（全局约束）**
- 描述：所有新功能保持纯前端实现（React + 原生 SVG，零第三方依赖、无 Node 原生依赖、无原生桥接）。
- 验收：构建产物在 Tauri WebView2 / 安卓 WebView / 苹果 WebKit 下功能一致；SVG data URI 为纯前端渲染，不影响打包。

### P1（重要，可在 P0 后一周内交付）

- E2 旧版软件导入新版 md 的兼容测试用例补充（含含涂鸦节/背景节的 md）。

### 2. 盘面爻行区域标记样式（建议，最终由架构师定）
- 旺相休囚死：地支五行右上角小字，可用五行配色区分（旺=红、相=橙、休=灰、囚=蓝、死=黑）。
- 月破/日破/月合/日合：爻行内角标如「破/合」或符号（✕/〇），与现有 nagan 角标并排、不重叠。
- 回头生/克/冲/合：动爻旁符号（↗生/↘克/↔冲/〇合）或小字。
- 化进退/反伏吟：化进「进」、化退「退」、伏吟「伏」、反吟「反」小标。
- 约束：标记区不遮挡爻位点击；画板开启时点击拦截优先级高于标记。

### 3. 画板工具栏布局（参考 QQ 截图）
- 位置：盘面顶部或侧边工具条，从左至右：画笔 → 文字 → 形状（矩形/圆形/画线/箭头）→ 颜色（预设色块 + 调色板）→ 粗细滑块（30 档）→ 外框/填充切换（矩形/圆形时可用）→ 撤销/清除 → 完成/关闭。
- 画板开关：盘面信息下方、地支分析上方，开关与工具栏联动。

### 4. 占断页文本框位置
- 顺序：卦题（title）→ **背景（新增）** → 断语 → 笔记（原「备注」改名）。

### 5. 卦身旁香闺/床帐样式
- 卦身显示处右侧追加：`香闺：寅木　床帐：子水`，与卦身同一行，等宽对齐；无结果时不显示该段。

## 四、边界与兼容性要求
1. **旧卦例兼容**：新字段（doodle/background/各标记快照）缺失时 UI 跳过、正常展示，不报错；旧卦例可正常打开/编辑/导出。
2. **旧 md 兼容**：无涂鸦/背景/笔记新节时照常导入；「备注」旧节名仍可导入并映射到笔记。
3. **新 md 反向兼容**：新版 md 被旧版导入不崩溃，仅丢弃新字段（涂鸦/背景/新标记）。
4. **多端打包**：全程纯前端、零第三方依赖、无原生桥接；Tauri/安卓/苹果三端行为一致。
5. **数据一致性**：涂鸦随卦例保存（record.doodle），导出/导入以 SVG data URI + JSON 元数据双向可逆。
6. **交互安全**：取消画板必弹确认（复用 ConfirmDialog），未确认不丢失涂鸦。
